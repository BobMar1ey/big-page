# Cuatro

Agency landing for a web designer and developer: hero, cases, process, testimonials, blog, and a hire-us form. Long one-page layout from Figma, with a burger menu and scroll animations.

**Live:** [albert-braun.github.io/big-page](https://albert-braun.github.io/big-page/)

## What it does

- **Header** — sticky nav, mobile burger
- **Hero / services** — premium design, development, and SEO pitch
- **Work** — selected cases and process steps
- **Social proof** — testimonials, about, blog cards, marquee
- **Footer + Hire us** — contact CTA overlay

**Stack:** React 19 · Create React App · CSS modules per section

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).
